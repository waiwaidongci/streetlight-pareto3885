# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。
- `outage_snapshots` 保存开算时的两路夜间记录、校时范围和灯数，供中断恢复。
- `outage_checks` 按快照指纹保存已验的夜间停灯偏移组合，供中断恢复和并发接手复用。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、运行、复核和报表分发动作。

本次为新增 `outage_snapshots`、`outage_checks` 两张表，不改动已有表列；应用启动时 `create_all` 会补建缺失表，已有运行首次被 worker 领取时按当前批次补建快照。
